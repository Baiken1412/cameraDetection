================================================================
软件许可证系统 - 快速上手指南
================================================================

一、首次设置（只做一次）
----------------------------------------------------------------
python generate_license.py --generate-keys

生成文件：
  ✓ private_key.pem  （私钥，保密！备份！）
  ✓ public_key.pem   （公钥，给客户）


二、客户申请许可证
----------------------------------------------------------------
客户运行：python main.py

客户会看到机器码，例如：
  机器码: 85003c68c4b40770027d59063acfe12789b775154c36c59df2232a264387ff3c

客户把机器码发给你。


三、生成许可证
----------------------------------------------------------------
# 1年期（365天）
python generate_license.py --create --machine-code 85003c68c4b40770027d59063acfe12789b775154c36c59df2232a264387ff3c --days 365

# 永久（9999天）
python generate_license.py --create --machine-code 85003c68c4b40770027d59063acfe12789b775154c36c59df2232a264387ff3c --days 9999

生成文件：license_85003c68.dat


四、发给客户
----------------------------------------------------------------
发送两个文件：
  1. license_85003c68.dat  （许可证，告诉客户改名为 license.dat）
  2. public_key.pem        （公钥）


五、客户安装
----------------------------------------------------------------
1. 改名：license_85003c68.dat → license.dat
2. 复制到软件目录（与 main.py 同级）：
   - license.dat
   - public_key.pem
3. 运行：python main.py


六、完整流程示例
----------------------------------------------------------------
你这边：
  1. python generate_license.py --generate-keys  （首次）
  2. 收到客户机器码：85003c68...
  3. python generate_license.py --create --machine-code 85003c68... --days 365
  4. 发送 license_85003c68.dat 和 public_key.pem 给客户

客户那边：
  1. 改名：license_85003c68.dat → license.dat
  2. 复制 license.dat 和 public_key.pem 到软件目录
  3. python main.py
  4. 成功！


七、注意事项
----------------------------------------------------------------
✓ private_key.pem 必须保密，定期备份
✓ 每个客户的机器码都不同
✓ 改名时注意文件扩展名是 .dat 不是 .txt
✓ license.dat 和 public_key.pem 必须放在 main.py 同级目录

✗ 不要把 private_key.pem 给客户
✗ 不要把 generate_license.py 给客户（可选）


八、常见有效期设置
----------------------------------------------------------------
1年:   --days 365
3年:   --days 1095
5年:   --days 1825
10年:  --days 3650
永久:  --days 9999


九、常见问题
----------------------------------------------------------------
Q: 提示"许可证文件不存在"
A: 检查文件名是否为 license.dat，是否在正确目录

Q: 提示"许可证与当前机器不匹配"
A: 重新获取机器码，重新生成许可证

Q: 更换硬件后许可证失效
A: 重新获取机器码，联系重新授权

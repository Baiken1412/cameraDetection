# 授权许可系统

## 关注主题（Topic of Concern）

基于 RSA 加密的软件许可证管理系统，控制功能授权和有效期。

---

## 需求描述

### 1. 许可证生成

- RSA 密钥对生成（private_key.pem / public_key.pem）
- 基于机器码绑定许可证（硬件指纹）
- 支持自定义有效期（1 年 / 3 年 / 5 年 / 永久）
- 许可证文件格式：`license.dat`

### 2. 许可证验证

- 系统启动时验证许可证
- 验证项：机器码匹配、有效期、签名完整性
- 验证失败时明确提示并限制功能

### 3. 部署流程

**厂商端**：
1. 生成密钥对：`python generate_license.py --generate-keys`
2. 收到客户机器码
3. 生成许可证：`python generate_license.py --create --machine-code <code> --days <N>`
4. 发送 `license_xxx.dat` + `public_key.pem` 给客户

**客户端**：
1. 运行程序获取机器码
2. 将 `license.dat` 和 `public_key.pem` 放入程序目录
3. 运行 `python main.py`

### 4. 安全要求

- `private_key.pem` 必须保密，不可分发给客户
- `generate_license.py` 不建议分发给客户
- 许可证与机器绑定，不可复制到其他机器

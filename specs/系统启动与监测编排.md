# 系统启动与监测编排

## 关注主题（Topic of Concern）

系统初始化流程、多摄像头编排、主循环管理、日志与监控。

---

## 需求描述

### 1. 启动流程

```
1. 系统初始化
   ├── 加载配置文件（config.json → config.py 回退）
   ├── 初始化日志系统（Loguru）
   ├── 验证许可证
   └── 创建数据库连接池

2. 创建 YOLO 池
   ├── 查询所有摄像头配置（从数据库）
   ├── 分析池需求（全局 / 分组 / 独立）
   └── 创建必要的 YOLO 实例池

3. 启动摄像头监测
   ├── 为每个摄像头创建 CameraMonitor
   ├── 分配 YOLO 池
   └── 启动监测线程

4. 主循环
   ├── 监控线程状态
   ├── 处理系统信号
   └── 资源管理与清理
```

### 2. 单摄像头监测流程（CameraMonitor）

- 管理单个摄像头的完整检测生命周期
- 视频流采集 → 帧率整形 → 变化检测 → YOLO 推理 → 结果存储
- 异常处理与自动重连
- 轨迹生成与合并
- 检测模式切换：快速模式（1 秒/次，有变化时）/ 慢速模式（10 秒/次，无变化时）

### 3. 日志系统

- 使用 Loguru 结构化日志
- 日志级别：DEBUG / INFO / WARNING / ERROR
- 日志文件自动轮转（默认 10MB）
- 日志保留：30 天
- 日志路径：`logs/rtsp_monitor.log`

### 4. 性能目标

| 指标 | 目标值 |
|---|---|
| 10 路摄像头总帧率 | > 10 fps |
| 内存（10 路 + YOLO 池） | 约 2GB |
| 单路 CPU 占用 | 约 30% |
| 系统连续运行 | 稳定 24 小时无崩溃 |

## 配置参数

```json
{
  "RTSP_MONITOR_CONFIG": {
    "sample_interval": 1,
    "detection_wait_interval": 10,
    "camera_api_url": "https://localhost:8090/caseapp/track/rtspStream",
    "camera_api_verify_ssl": false,
    "camera_api_timeout": 10,
    "recent_records_minutes": 30
  },
  "LOG_CONFIG": {
    "level": "DEBUG",
    "format": "{time:YYYY-MM-DD HH:mm:ss} | {level} | {name}:{function}:{line} | {message}",
    "file": "logs/rtsp_monitor.log",
    "rotation": "10 MB",
    "retention": "30 days"
  }
}
```

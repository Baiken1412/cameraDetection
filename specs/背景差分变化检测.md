# 背景差分变化检测

## 关注主题（Topic of Concern）

基于背景建模算法的画面变化检测，只在检测到变化时才触发 YOLO 推理，节省计算资源。

---

## 需求描述

### 1. 背景建模算法

- 支持 MOG2（混合高斯模型，默认）
- 支持 KNN（K 近邻）
- 背景自适应学习（学习率 0.001，适应长期环境变化）
- 历史帧数：500 帧建立背景模型
- 阴影检测：开启，减少阴影误报

### 2. 变化检测规则（三重过滤）

| 过滤层 | 参数 | 默认值 | 说明 |
|---|---|---|---|
| 变化阈值 | change_threshold | 0.02 (2%) | 画面变化超过 2% 才触发 |
| 连续帧确认 | consecutive_frames_threshold | 2 | 需连续 2 帧变化才确认 |
| 最小变化面积 | min_change_area | 500 像素 | 忽略小于 500 像素的微小变化 |

### 3. 形态学处理

- 对前景掩码进行形态学操作（开/闭运算），去除噪点
- 形态学操作类型可配置

### 4. 检测流程

```
输入帧 → 背景减除 → 前景提取 → 形态学处理 → 面积计算 → 阈值判断 → 是否触发 YOLO 检测
```

### 5. 业务规则

- 无变化时跳过 YOLO 检测，大幅降低 CPU 负载
- 检测到变化时切换为快速模式（1 秒/次）
- 无变化时切换为慢速模式（10 秒/次）

---

## 配置参数

```json
{
  "RTSP_MONITOR_CONFIG": {
    "change_threshold": 0.02,
    "consecutive_frames_threshold": 2,
    "min_change_area": 500,
    "morphology_operation": 1,
    "bg_subtractor_type": "MOG2",
    "bg_learning_rate": 0.001,
    "bg_history": 500,
    "bg_var_threshold": 10,
    "bg_detect_shadows": true
  }
}
```

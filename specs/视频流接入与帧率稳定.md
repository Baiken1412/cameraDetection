# 视频流接入与帧率稳定

## 关注主题（Topic of Concern）

RTSP / USB 视频流的采集、缓冲管理、帧率整形，确保检测流水线获得稳定的输入。

---

## 需求描述

### 1. 视频流采集

- 支持 RTSP 协议视频流（网络摄像头）
- 支持 USB 本地摄像头（调试/演示用）
- 采用独立线程读取视频流（`VideoStreamReader`），避免主线程阻塞
- 断线自动重连，重连间隔可配置（默认 5 秒）
- 最大重连次数可配置（默认 3 次）
- RTSP 连接超时可配置（默认 30 秒）
- 支持 PyAV 读取以获取精确 PTS 时间戳

### 2. 输入整形层（InputShaper）

- 将不稳定的 RTSP 流（如 25fps）转换为稳定帧率输出（默认 2fps）
- 环形缓冲区管理，缓冲区大小可配置（默认 30 帧）
- 丢帧策略：缓冲区满时丢弃旧帧（drop_old），保证实时性
- 空缓冲区行为：跳过（skip）
- 帧时间戳正确传递

### 3. 缓冲区管理

- 定时清理缓冲区（默认每 10 秒）
- YOLO 检测后清理缓冲区（每 100 帧后清理一次）
- 最大缓冲帧数限制（默认 150 帧）

## 配置参数

```json
{
  "RTSP_MONITOR_CONFIG": {
    "use_video_stream_reader": true,
    "buffer_flush_interval": 10,
    "buffer_flush_max_frames": 150,
    "buffer_flush_after_yolo_frames": 100,
    "reconnect_interval": 5,
    "max_reconnect_attempts": 3,
    "rtsp_timeout": 30,
    "timestamp_strategy": "realtime",
    "enable_usb_camera": true,
    "usb_camera_id": 0
  },
  "INPUT_SHAPER_CONFIG": {
    "enabled": true,
    "target_fps": 2.0,
    "buffer_size": 30,
    "drop_strategy": "drop_old",
    "empty_behavior": "skip"
  }
}
```

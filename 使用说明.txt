========================================
RTSP 摄像头监测系统 - 使用说明
========================================

一、系统要求
--------------------
- 操作系统: Windows 10/11 (64位)
- 内存: 建议 8GB 以上
- 硬盘空间: 至少 10GB 可用空间
- 数据库: MySQL 5.7 或更高版本

二、安装与配置
--------------------
1. 无需安装 Python 环境，本程序已包含所有依赖

2. 确保 MySQL 数据库已安装并运行

3. 导入数据库:
   - 找到程序目录中的 init_cameras.sql 文件（如果有）
   - 在 MySQL 中创建数据库并导入该文件

4. 配置文件说明 (重要！)
   - 程序目录下有一个 config.json 配置文件
   - 使用 VSCode、Notepad++ 或记事本打开 config.json 即可修改配置
   - 主要配置项：

     {
       "DATABASE_CONFIG": {
         "host": "localhost",        // 数据库地址
         "port": 3306,               // 数据库端口
         "user": "root",             // 数据库用户名
         "password": "1412",         // 数据库密码（修改这里）
         "database": "caseappdb"    // 数据库名称
       },
       "RTSP_MONITOR_CONFIG": {
         "image_save_path": "D:/appdata/uploadPath/caseapp",  // 图片保存路径（修改这里）
         "camera_api_url": "https://localhost:8090/caseapp/track/rtspStream"  // API地址（修改这里）
       },
       "ADAPTIVE_DETECTION_CONFIG": {
         "conf_threshold": 0.5,  // 检测置信度阈值（0.0-1.0）
         "iou_threshold": 0.4    // IOU阈值（0.0-1.0）
       }
     }

   - 修改后保存文件，重启程序即可生效
   - 注意：JSON 格式不支持注释，上面的 // 仅用于说明，实际文件中不要添加

三、运行程序
--------------------
1. 双击 CameraMonitorSystem.exe 启动程序

2. 程序会自动:
   - 加载 config.json 配置文件
   - 检查许可证（如果启用）
   - 连接数据库
   - 读取摄像头配置
   - 启动监测服务

3. 日志文件会保存在 logs 文件夹中

四、注意事项
--------------------
1. 首次运行可能需要较长时间加载 AI 模型

2. 确保摄像头 RTSP 地址正确且可访问

3. 如果使用 GPU 加速，需要安装对应的 CUDA 驱动

4. 程序运行时会占用较多内存和 CPU/GPU 资源

5. 按 Ctrl+C 可以安全退出程序

6. 修改配置后必须重启程序才能生效

五、目录结构
--------------------
CameraMonitorSystem.exe  - 主程序
config.json              - 配置文件（可直接修改）
使用说明.txt            - 本说明文件
_internal/               - 依赖文件和资源（请勿修改）
  ├── models/            - AI 模型文件
  ├── static/            - Web 界面静态文件
  ├── templates/         - Web 界面模板
  └── data/              - 数据存储目录
logs/                    - 日志文件目录

六、常用配置修改示例
--------------------
1. 修改数据库连接:
   打开 config.json，找到 DATABASE_CONFIG，修改对应的值
   例如："password": "你的密码",

2. 修改图片保存路径:
   打开 config.json，找到 RTSP_MONITOR_CONFIG，修改 image_save_path
   例如："image_save_path": "D:/你的路径/uploadPath/caseapp",

3. 调整检测灵敏度:
   打开 config.json，找到 ADAPTIVE_DETECTION_CONFIG：
   - 降低 conf_threshold 提高灵敏度（检测更多目标，但可能误报）
     例如："conf_threshold": 0.3,
   - 提高 conf_threshold 降低灵敏度（减少误报，但可能漏检）
     例如："conf_threshold": 0.7,

4. 修改摄像头API地址:
   打开 config.json，找到 RTSP_MONITOR_CONFIG，修改 camera_api_url
   例如："camera_api_url": "https://你的服务器:8090/caseapp/track/rtspStream",

七、故障排除
--------------------
1. 程序无法启动:
   - 检查是否有杀毒软件拦截
   - 确保有足够的系统权限
   - 查看 logs 文件夹中的日志文件

2. 无法连接数据库:
   - 检查 MySQL 服务是否运行
   - 确认 config.json 中的数据库配置正确
   - 检查防火墙设置

3. 摄像头无法连接:
   - 确认 RTSP 地址正确
   - 检查网络连接
   - 确认摄像头在线

4. 配置修改不生效:
   - 确认已保存 config.json 文件
   - 重启程序（修改配置后必须重启）
   - 检查 JSON 语法是否正确（注意格式、引号、逗号等）
   - 可以使用在线 JSON 验证工具检查格式: https://jsonlint.com/
   - 如果修改后程序报错，可以从源码目录复制一份备份

5. 找不到 config.json 文件:
   - config.json 应该与 CameraMonitorSystem.exe 在同一目录
   - 如果丢失，可以从源码目录复制一份

6. 修改 config.json 后程序报错:
   - 检查 JSON 语法是否正确
   - 常见错误：
     * 字符串必须用双引号："localhost"（不能用单引号）
     * 最后一个属性后面不能有逗号
     * 布尔值必须小写：true/false（不能用 True/False）
     * 不能有注释（// 或 /* */）
   - 如果不确定，可以从源码恢复原始 config.json

八、技术支持
--------------------
如有问题，请查看日志文件获取详细错误信息

修改 config.json 配置文件时注意：
- 字符串值必须用双引号包裹："localhost"（不能用单引号）
- 数字值不需要引号：3306
- 布尔值用小写：true/false（不能用 True/False）
- 最后一个属性后面不能有逗号
- JSON 不支持注释（不要添加 // 或 /* */）
- 保持原有的缩进格式
- 可以使用 JSON 验证工具检查格式
